# Prompt registry

Pedagogical prompts are versioned references, not execution authorization.

- **Runtime source:** the current Agenda Feedback Prompts cells, read by
  `adapters.agenda_prompts`. See [Agenda prompts](../docs/AGENDA_PROMPTS.md).
- **Reviewed release reference:** `web/teacher-prompts.json`, currently the
  September 15 feedback-v2 revision. See [feedback v2](../docs/FEEDBACK_V2.md).
- **Historical source:** `teacher-feedback-20260914.txt` preserves the earlier
  supplied Prompts 1–3. Its seven-section feedback format and next-lesson language
  are superseded. Do not use it as the current runtime prompt or overwrite v2.
- `synthetic-feedback-v1.md` is fictional and exercises version traceability only.

When real prompt content changes, reconcile the live Agenda, reviewed reference,
matching skill/manual and dashboard together. Prompt alignment does not authorize
student processing or school writes.
