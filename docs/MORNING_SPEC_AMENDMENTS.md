## A. Where feedback and teacher-only documents are saved

The spec says both "Save feedback Google Docs … in the matching course/lesson turn-in folders" and "never put named feedback into" the public Turn It In folders. Turn It In course and week folders are shared "anyone with the link can view", so the second rule wins:

- Save the student feedback Doc, the growth record and the class summary in the matching private course folder under "Student Feedback — Private 2026–27": 🌿 Biology — Private feedback, 🔬 Forensics — Private feedback, or 🫀 A&P — Private feedback. This applies to Prompt 2 Steps 3–5 ("in the same folder") as well.
- Before every write, re-read the folder's sharing. Only the teacher's school account may have access. If anyone else does, hold the write and report it.
- Prompt 2 Step 1, reading growth so far: search the private course folders for "Growth record — <class>" Docs. On October 1 the existing Forensics Wk 05 records (Sep 29 and Sep 30) were moved there from the Wk 05 turn-in folder.
- Nothing with a student's name goes into Turn It In, ever.

## B. One checklist, private, with a tab per course

The spec asks for both a per-course print checklist "directly in its existing icon-labelled course folder inside Turn It In" and "one private searchable Google Sheets feedback checklist". The Turn It In copy would put student names in a public folder. Instead:

- Make one Google Sheet, "Feedback checklist 2026–27", in "Student Feedback — Private 2026–27".
- Give it one tab per course (Biology, Forensics, A&P), so each course has its own searchable list filterable by lesson. Use the columns, checkbox rules, Superseded rule, Needs review rule and Ready to print view exactly as the spec describes.
- Put no checklist in Turn It In.
- The Hub's "Mark feedback done" and the Routine page's printed list (`docs/ROUTINE_CHANGE_HANDOFF.md` §3) should read this Sheet's Printed and Handed to student columns, not keep a second record.

## C. Tidy rules that used to live in the Hub

The Hub's own Tidy is being removed (`docs/ROUTINE_CHANGE_HANDOFF.md`). The Hub's counts, 0s and scoring still expect what it did, so the 6:30 tidy must keep these:

1. Exactly one 📥 week folder per course per week: `00 REAL ALL TURN IN / <icon course> / 📥 Wk NN — <Topic>`. Each Form's "(File responses)" folder stays inside it. Never move, rename or delete a Form's response folder.
2. Work turned in more than two weeks after the assignment window opened goes into that week folder's "⏰ Late — not graded" subfolder, and is not graded.
3. Put the student's name and lesson in front of each turned-in file's name ("Ana Rivera.Energy Flow - <original name>"). The Hub reads the original name behind the prefix, so matching and turn-in times don't change.
4. A deck turned in through another lesson's Form stays where it is. The Hub already credits it to the right lesson by its content. Moving it can break that.

## E. Roster

The spec's title includes the roster, but no step adds students, and the Hub's roster check is status-only. Until the teacher decides who adds new students, report new or missing students in the morning summary. Change nothing in the Rosters sheet.

- Prompt 2's section "IF I ASK FOR FEEDBACK FOR A STUDENT WITH NO WORK FOR THIS LESSON" now applies automatically. It applies to every student on the roster who turned in nothing for the latest closed lesson. It also applies to students whose only file arrived after the two-week window, which is late work and isn't graded. Drop the "only after I confirm" condition. Use that section's exact wording and its "My commitment for next time" contract.
- Put these students on the checklist like anyone else, with Status "Commitment — missing" or "Commitment — late", so they are printed and handed out with the rest.
- Don't invent levels, quotes or growth for them, and don't add growth record rows.
